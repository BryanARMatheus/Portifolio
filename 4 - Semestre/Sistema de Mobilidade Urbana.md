
## 1. Descrição do Projeto

O desafio do quarto semestre consistiu no desenvolvimento de uma **Plataforma de Inteligência de Dados Orientada à Mobilidade Urbana**, voltada para o monitoramento de radares e fluxo viário do município de São José dos Campos. O sistema realiza a ingestão e a análise de grandes volumes de dados de telemetria urbana, transformando registros brutos de tráfego em _dashboards_ interativos e indicadores gerenciais estratégicos. O produto foi projetado para atender tanto às demandas operacionais de gestores públicos da **Prefeitura de São José dos Campos** quanto às necessidades de consulta informativa do cidadão comum.   

## 2. Contribuição para o Projeto

Com atuação focada nas frentes de **Front-end** e **UI/UX Design**, fui responsável pela concepção da experiência do usuário, estruturação do visual do site e desenvolvimento de mecanismos de integração da interface.

Durante o projeto, percebi que o maior desafio no front-end seria exibir uma alta densidade de dados de forma fluida sem poluir a tela com alta quantidade de informações. Para garantir que a nossa equipe não ficasse paralisada aguardando o back-end finalizar a ingestão e integração dados dos radares ao banco, projetei e implementei uma Camada de Simulação (Mock) no código. Espelhei os contratos de banco de dados na nossa aplicação Vue.js, permitindo o desenvolvimento e teste das interfaces do frontend.

Outro ponto seria que nosso time não possuía um modelo a ser seguido ao desenvolver o frontend, logo tomei frente e decidi construir um wireframe, garantindo a consistencia da interfface em todos os componentes e o fluxo de experiencia do usuário, precisei entender como aplicar as funcionalidades do projeto a uma tela real do zero, isso me fez entender muito mais a fundo sobre o projeto do que os semestres anteriores, pois era necessário não só imaginação mas muita criatividade na hora de portar as User stories para o wireframe.
    

## 4. Lições Aprendidas (Soft Skills & Hard Skills)

### Soft Skills
Como precisei desenvolver o design, foi necessário observação e comunicação com o time e PO para entender se o design realmente estava refletindo a funcionalidade que a história atendia, além disso precisei considerar a experiencia da equipe com frontend e o que seria possível ser feito.

Ademais ajudei também a manter o código limpo e estruturado pois já tinha uma experiencia e conceitos que aprendi anteriormente no frontend, então auxiliei e expliquei como o desenvolvimento funcionava para os outros desenvolvedores, isto me fez entender ainda mais sobre como realizo o desenvolvimento, considerando e organizando meu processo para desenvolver uma tela de uma maneira que funcione como explicação.

### Hard Skills

- **Engenharia de Front-end (Vue.js, Axios & Mocking):** Criei componentes mais complexos, continuei evoluindo a habilidade de  consumo assíncrono de APIs e simulação de dados do backend no frontend para separar o desenvolvimento, isso me deu um entendimento mais profundo sobre qual era a estrutura dos dados que o time estava utilizando.
    
- **Design de Interface & Experiência do Usuário (UI/UX):** Utilizei o Figma para prototipação, definição de fluxogramas de usuário para a aplicação, aprendi sobre teoria das cores aplicada à acessibilidade e design focado na legibilidade de dados, isso me ensinou a entender melhor como o usuário utiliza e o que ele procura quando acessa a aplicação.
    
- **Estilização (SASS):** Implementação de arquiteturas CSS modulares com SASS, utilizando variáveis, mixins e aninhamentos para reaproveitamento de código técnico auxiliando em deixar o código mais limpo e legível.
    
- **Infraestrutura em Nuvem e Banco de Dados:** Ajudei o time na modelagem de dados (DER), tambem continuamos evoluindo na aplicação da normalização de tabelas e prática na utilização de recursos de banco de dados relacionais em ambientes Cloud (Oracle Cloud Infrastructure).
    
- **Docker:** Prática no empacotamento de aplicações web e gerenciamento de contêineres multi-ambiente, garantindo o funcionamento da aplciação em diversos ambientes.
