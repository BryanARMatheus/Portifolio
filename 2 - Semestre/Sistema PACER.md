## Descrição do Projeto
Neste projeto, desenvolvemos um Sistema Desktop de Avaliação baseado na Metodologia PACER, voltado para a gestão de desempenho e avaliação de soft skills entre colegas de equipe. O grande problema que resolvemos foi automatizar e centralizar um processo de coleta de notas que era manual, disperso e propenso a erros, fornecendo um dashboard analítico rápido e seguro para os professores.

### Contribuição para o Projeto

Atuei de ponta a ponta (Full-Stack), foi minha primeira experiência com o modelo de Backend e Frontend, Java foi um grande passo do TypeScript utilizado anteriormente, entender e compreender a sintaxe para executar as consultas e regras de negócio das tarefas foi uma ótima experiencia de aprendizado, criei a função de processamento de CSV, lendo arquivos .csv enviados pelo usuário direto do front, verificando se a formatação de dados está correta para conseguir gravar as informações do pacer corretamente no banco de dados, além disso criei a lógica principal da aplicação de média ponderada para mostrar corretamente a nota dos estudantes considerando todas as votações feitas do grupo. 

Nosso front foi feito com JavaFX e Scene Builder para facilitar a programação e conexão com o backend, foi uma experiencia sem atritos, trabalhei sobre a pagina de alunos adicionando alguns aspectos e campos para melhorar a visualização do usuário, tela de importação de CSV, ela também incluia uma pré visualização dos dados csv formatados em tabela, ademais a tabela de média ponderada dos grupos de alunos para visualização do professor.

### Soft Skills

Esse projeto exigiu forte Colaboração. Como a aplicação envolvia regras de negócio, precisei alinhar constantemente as interfaces técnicas com o time, garantindo que o fluxo das telas que eu construía conversasse perfeitamente com os controladores dos outros desenvolvedores.
Isso fortaleceu minha Adaptabilidade, pois integramos requisitos técnicos iterativamente sem perder o ritmo das entregas, também precisou de Responsabilidade da minha parte em comunicar minha equipe sobre o andamento das tarefas e desenvolver minhas features dentro de uma data aceitável.

### Hard Skills
- Java & JavaFX: Meu primeiro contato com Java e JavaFX, precisei desenvolver a habilidade de criar consultas e exibir os dados para visualização do usuário, trabalhei em diversas classes e implementação do backend em Java com o frontend em JavaFX.

- MySQL: Precisei executar diversas consultas e criar tabelas no banco para comportar minhas tarefas, sempre exercendo os ensinamentos das aulas de estrutura de tabelas do banco de dados, utilização das formas normais e relacionamentos.
